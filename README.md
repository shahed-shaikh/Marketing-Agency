MARKUP is a creative digital marketing agency website built with HTML5, CSS3, and Bootstrap 5. Its bold visual identity, vibrant graphics, and clear messaging create an engaging online presence for a marketing studio.

The homepage introduces the agency with a strong hero statement, creative visuals, and calls to action. A brand showcase highlights businesses the agency helps grow, while the About section presents its team and key statistics. The services section features Brand Strategy, Social Media, Digital Advertising, and Creative Design.

A selected work gallery presents two concepts: Fresh Co. for brand identity and Motion for a digital campaign. The contact section invites visitors to connect, and the footer provides brand messaging and quick links.

The project uses Bootstrap 5 for its layout and a separate CSS file for styling. It demonstrates structured sections, responsive design foundations, clear navigation, service presentation, portfolio layouts, and consistent branding. The result is a polished agency website focused on creativity, brand growth, and digital marketing.
